# ADR-045: Build the new pipeline on PayCo SDK v5

Decision: the new reconciliation pipeline uses PayCo SDK v5 (streaming settlement API) rather than v4.
Risk accepted: v5 was in early access; GA was promised for 2026-08-10.
Consequence: Apollo's go-live depends on PayCo's v5 release and certification.
