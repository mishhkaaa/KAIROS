# Apollo budget and variance

Why Project Apollo is over budget: actuals are 31% over the approved budget.

| Line item | Budget (lakh) | Actual (lakh) |
|---|---|---|
| Engineering | 12.0 | 14.5 |
| Cloud | 5.0 | 6.9 |
| Vendor licences | 3.0 | 4.8 |
| Total | 20.0 | 26.2 |

Overrun: 6.2 lakh (31%). The cloud cost increase came from running the old and new reconciliation
pipelines in parallel for 7 weeks because the database migration slipped.
The vendor licence overrun came from an emergency SDK support contract.
