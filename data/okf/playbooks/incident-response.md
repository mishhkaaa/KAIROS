# Incident response playbook

1. Declare the incident and severity in #incidents.
2. Assign an incident commander and a scribe.
3. Mitigate first, then find the root cause.
4. Write a postmortem within five working days (see the [backfill postmortem](../engineering/postmortem-backfill-failure.md)).
